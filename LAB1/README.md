
Python Lab 1

1. Variable and Identifier Practice

Aim

To declare variables of different data types and display their values and types.

Logic

Four variables are created for name, age, height, and student status. The type() function is used to display the data type of each variable.

Sample Input / Output

No input is required.

Output:

Name: Nishi Type: <class 'str'>
Age: 22 Type: <class 'int'>
Height: 5.3 Type: <class 'float'>
Is Student: True Type: <class 'bool'>

1. Greeting Program

Aim

To take the user’s name, age, and city and display them in one sentence.

Logic

The program takes three values using input(). An f-string is used to combine all three values into one sentence.

Sample Input / Output

Input:

Name: Nishi
Age: 20
City: sendhwa

Output:

My name is Nishi, I am 20 years old, and I live in sendhwa.
